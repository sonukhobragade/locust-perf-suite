# Runtime dependencies, kept to what the suite actually imports.
#
# This file was previously a catalogue of everything a load test might one day
# talk to: Kafka, AWS, MongoDB, Postgres, MQTT, InfluxDB, pandas and numpy.
# Nothing in the repository imported any of them. They took the install from
# 77MB to 342MB, so 265MB was downloaded before anyone could run their first
# load test, and each pin was a dependency to keep patched for code that did
# not exist.
#
# Two rules for what belongs here: something a module imports, or a transitive
# dependency this suite deliberately pins. Anything else goes.
#
# `make deps` checks the first rule against the source, and the gate runs it.

# --- load driver -------------------------------------------------------------
# Brings its own requests and gevent. Neither is imported directly here, so
# neither is listed; pinning them separately would only create a second place
# for a Locust upgrade to conflict with.
locust==2.43.4

# --- util/locust_metrics.py --------------------------------------------------
prometheus-client==0.20.0
# Locust pulls Flask in for its own web UI, so `from flask import ...` in
# locust_metrics.py worked without ever being declared. Relying on that meant a
# Locust release that changed its UI stack would have broken this suite with no
# line in this file to explain why.
flask>=3.0,<4

# --- util/grpc_helper.py -----------------------------------------------------
grpcio==1.62.1
# Generated stubs import protobuf at runtime. grpcio-tools generates them and
# is a build-time tool, so it lives in requirements-dev.txt instead.
protobuf>=3.20.0,<5.0

# --- configuration -----------------------------------------------------------
python-dotenv==1.0.1
